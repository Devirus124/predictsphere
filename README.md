# PredictSphere — Always-On Sports Prediction Game

Extreme 3D Glassmorphic NFL & NBA prediction arena with an autonomous AI agent.

## Features
- Always-on agent that cycles every few hours, predicts winners + confidence + reasoning
- Self-grading + “what I learned” notes
- Beautiful floating glassmorphic onboarding modal
- 1,000 starting prediction points
- Live dashboard, copy-agent-picks, real-time style leaderboard, chat with the agent
- Full extreme 3D glassmorphism (perspective 1400px, tilt cards, drifting blobs, neon edges)

## Live Demo
Open the `index.html` file directly in any modern browser, or serve it with any static host.

After enabling **GitHub Pages** (Settings → Pages → Deploy from main branch / root), the public URL will be:

**https://devirus124.github.io/predictsphere/**

## Local Run
```bash
cd sports-prediction-game
python3 -m http.server 8080
# then open http://localhost:8080
```

The complete self-contained application (single HTML file with all CSS/JS) lives in this repository.

Built for demos — agent reasoning is highly visible, UI is premium and immersive.
